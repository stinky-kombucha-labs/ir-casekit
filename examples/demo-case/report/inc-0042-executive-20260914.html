Leaked ci-deployer key used to read the customer exports bucket

The access key of IAM user ci-deployer was pushed to a public repository on 2026-09-12 20:41 UTC. An external address used it 26 minutes later, created a backdoor user and read 1 090 objects (2.31 GB) of customer exports for July and August 2026. The client disabled the key on 2026-09-13 09:41 UTC; the actor made no successful call after that. The database password from the same file is not yet proven rotated.
